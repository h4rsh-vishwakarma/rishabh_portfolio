# Rishabh Vishwakarma — Video Editor Portfolio

## GitHub Pages setup

1. Push this folder to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/docs` folder.
5. Save and wait for GitHub Pages to publish the site.

The live site entry point is `docs/index.html`. All CSS, JavaScript, videos, favicon and resume files are kept inside `docs/` with relative paths so the site works on project URLs such as `https://username.github.io/repository-name/`.
